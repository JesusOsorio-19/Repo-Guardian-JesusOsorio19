# Repo-Guardian-JesusOsorio19
**Repo-Guardian** es un proyecto de desarrollo de software avanzada cuyo resultado será una utilidad de línea de comandos (CLI) y  terminal user interface (TUI) capaz de **auditar, reparar y re-lineralizar la integridad de cualquier directorio `.git`**, ya contenga objetos sueltos ("loose") o empaquetados en packfiles.
